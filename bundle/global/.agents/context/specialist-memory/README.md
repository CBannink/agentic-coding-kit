# Global Specialist Memory

Cross-repo specialist guidance for reusable agents. Keep these files small and
high signal. Repo-specific facts belong in `.kit/context/agent-memory/`.

Rules:
- max 1200 lines per role file
- one bullet per durable pattern
- no secrets, credentials, customer data, or task progress
- write only lessons useful across multiple repos
- prefer concrete "watch for X when Y" guidance over generic advice
