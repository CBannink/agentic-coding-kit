# Plan Skill — Accumulated Knowledge

Cross-repo planning patterns confirmed across multiple planning sessions.
**Scope**: global skill-level (not repo-specific).

- Repo facts → `.codex/context/memory.md`
- Session plans → `~/.agents/session-state/{id}/plan.md`
- Workflow improvement proposals → `~/.agents/context/reflections.md`

## Write Gate
Before adding an entry ask: "Would this planning pattern help a future /plan session in a completely different repo?"
If no → write to the session plan or private handoff instead.

## Format
```text
- [DATE] [H/M/L confidence] [domain: planning|scope|verification|parallelism]
  Pattern: {one-line}
  Evidence: {where confirmed — repo or session context}
  Apply when: {trigger condition}
```

Max 20 entries. Promote to plan/SKILL.md if confirmed HIGH in 3+ repos.
