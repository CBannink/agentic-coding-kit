# Review Skill — Accumulated Knowledge

Cross-repo patterns confirmed across multiple /review sessions.
**Scope**: global skill-level (not repo-specific).
- Repo review traps → `.kit/context/memory.md`
- Session findings → `~/.agents/session-state/{id}/handoffs.md`
- Workflow gaps → `~/.agents/context/reflections.md`

## Write Gate
Before adding an entry ask: "Would this pattern help a future /review session in a completely different repo?"
If no → write to the session private handoff instead.

## Format
```
- [DATE] [H/M/L confidence] [domain: false-positive|trap|pattern|heuristic]
  Pattern: {one-line}
  Evidence: {where confirmed — repo or session context}
  Apply when: {trigger condition}
```
Max 20 entries. Promote to review/SKILL.md if confirmed HIGH in 3+ repos.
