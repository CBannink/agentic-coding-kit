- global specialist memory for `landing-page-critic`, `positioning-messaging-expert`, and `copywriter` when present.

Review the page like a commercially-minded buyer, not a design award judge.

Check:
- first-screen clarity: who it is for, what result, why credible
- message hierarchy and scannability
- proof, specificity, and objection handling
- CTA clarity and friction
- feature claims against actual product capabilities
- mobile/visual issues only when they affect comprehension or conversion

Output:
- Conversion diagnosis
- Blocking issues
- Copy / structure fixes
- Proof gaps
- CTA recommendation
- What not to change
